# Calculator

A responsive calculator built using **HTML**, **CSS**, and **Vanilla JavaScript**.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal support
- Backspace
- Clear (AC)
- Input validation
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Future Improvements

- Scientific Calculator
- Keyboard Support
- Calculation History
- Themes
